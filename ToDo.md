- Feat: Standalone show on an OpenHaunt node (what the OctoBanger was). Design: ROADMAP *standalone-node-show*, OpenHaunt/node doc 16
    - One flow + up to 4 timelines (OctoBanger shape: ambient + scare) exported to one node, which runs them with no console: PIR triggers, ambient/scare, reset by the scare's end
    - Standalone only, no fallback: the-pult deploys and switches the node, the flag survives reboots, the-pult (or the node's page) switches it back. Leaving: stop, outputs to port defaults
    - Each node alone, no peers. Edited only in the-pult; the node's page shows status, presses the flow's Buttons, and has one master volume (kept until the next deploy)
    - Strict subset, validated: the node's own ports and speaker, variables, its timelines, the flow kinds. Sequences/cues, other fixtures, speed master block the export and are named. A zone clip plays the node's part, the other members are listed
    - New flow kind `Started` (pulse when the flow starts). Arming delay is Started → Delay → armed + Gate; the OctoBanger importer turns boot_delay_s into that
    - Firmware: flow interpreter + track player in oh_core (pure C, host tests), on the S3 for V0. Package is a file on the clips FAT and pins its clips (planner counts them as wanted, node answers 409 to DELETE)
    - Package carries a hash: the-pult shows "out of date" with Redeploy, never uploads on its own. Redeploy = stop, upload, check, restart; a bad package keeps the old one. Bad package or missing clip at boot: doesn't run, says why
    - Variables reset to initial at boot. Status read-only on MQTT when a broker is there; output/audio commands ignored while standalone
    - Fixed DMX out via sACN: a standalone node can send a fixed universe (or the values its flow/timelines drive) as sACN to a DMX gateway on its own cable, with no console.
